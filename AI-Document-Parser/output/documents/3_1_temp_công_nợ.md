# Giao diện mẫu (Template) - 3.1 temp công nợ

## 1. Filter (Bộ lọc)
- Loại nợ: Dropdown
- Nợ trước hạn: Dropdown
- Nợ quá hạn: Dropdown
- Nhóm khách hàng: Dropdown
- Tên khách hàng: Search

## 2. Card (Chỉ số tổng quát)
- Số nợ đầu kỳ **|** Số nợ phát sinh **|** Số nợ đã được thanh toán **|** Số nợ còn lại

## 3. Chart (Biểu đồ)
- Công nợ quá hạn *(Stacked column chart)*: Có trục X chia làm các phần 0-30, 30-60, 60-90
- Công nợ theo từng nhóm khách hàng *(Clustered column chart)* **|** Phân tích nợ theo loại nợ *(Stacked column chart)*
- Phân tích nợ trước hạn *(Stacked column chart)*: Có trục X chia làm các phần 0-30, 30-60, 60-90
- Chi tiết công nợ theo khách hàng *(Table)*: Mã KH, Tên KH, Chi nhánh, Số nợ đầu kỳ, Số nợ phát sinh trong kỳ, Số tiền đã trả, Số còn phải trả, Địa chỉ
